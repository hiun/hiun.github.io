검색에 대하여.

검색에 대해서 의견이 많다.
서비스로써의 검색, 기술로써의 검색 등 이를 바라보는 다양한 관점이 있다.
검색 성능에 대해 생각해보자.
검색 성능이란 기본적으로 쓸만한 결과가 나오는지에 대한 것이 되겠다.
근데 이것을 도달하기 위해 방법은 여러가지가 있다.

하나는 검색 색인의 규모를 늘리는 것이다,
그러러면 양적 질적으로 좋은 데이터를 소싱하는게 필요하다.
그것을 위해 서비스를 만들 수 도 있겠다.
이를 위해 필요한것은 시스템 효율화이다.
분산처리, 검색 엔진 기술, 등 서빙 소프트웨어 시스템의 개선이 있겠다.
더 나아가 하드웨어 자체의 발달도 중요하겠다.

이러한 성능 개선은 어퍼바운드가 있다.
좋은 데이터가 있어도 검색이 안되는 경우이다.
이를위해 기술로써의 검색이 필요하다.
어떻게 검색이 잘 되게 할 것인가에 대한 탐구가 되겠다.
시스템이나 하드웨어는 이 검색 기술을 가속화하고, 더 빠르게 돌리는 역할을 하게 된다.

===

검색이라는 서비스를 어떻게 characterize 할 수 있을까?
우선 검색과 비슷한 LLM 으로 부터 생각을 시작해보자.
특정한 주제에 대한 탐구라는 기준으로 보면,
LLM 은 주제에 대한 깊은 탐구를 잘 하는듯 하다.

```
LLM:
|   |
| | |
| | |
  |
```

검색은 주제에 대한 다양한 탐구를 잘 하는데 적합한것 같다.

```
검색:
.        .  ..
. .  ..  .   .
. .  .   .   .
```

광고 및 추천 시스템을 살펴보면,
주제를 중심으로 탐구하기 보다,
친구, 광고주와의 연결 관계를 중심으로 탐구 한다.
따라서 주제 관점에서는 일관성이 오히려 없다.

```
광고/추천 시스템:
---- ------- ---
--------- ------
- --------- ----
```

주제에 대한 granularity 를 기준으로 보면,
가장 coarse-grained 한것은 LLM 이고,
중간이 검색,
가장 fine-grained 한것이 광고/추천 시스템이 될 수 있겠다.

문제는 LLM 처럼,
granularity 가 너무 coarse 하면
그것으로 사람이 무언가 할 자유도를 얻기가 어려우며,

광고/추천 시스템처럼 granularity 가 너무 fine 하면,
모래알과 같은 정보 들로 그것들을 조합하기가 어려울 수 있다는 것이다.

검색의 특징은, middle granularity 를 가지는것으로 생각 되며,
그 결과를 사람이 잘 조합하여, 큰 그림을 그릴 수 있는 게 아닐까 싶다.

당연히 검색에게 task 자체를 완전히 위임하는 건 어렵다
검색은 그것을 사람이 하는것을 어느정도 전제하고 있기 때문이다.

새로운 발견만을 추구할수도 없다,
검색은 기본적으로 주어진 informational task 에 대해서 진행 되기 때문이다.

즉 검색은 사람이 어느정도 생각하는데 도움이 되는 granularity 를 제공하는 셈이 된다.

===


```
user context poor-to-rich of task
|
|          /  topical granularity fine-to-coarse of task
|        /
|      /
|    /
|  /
|/______________  degree of user passiveness-activeness of task
```

상기 처럼 informational task 를 분류 해볼 수 있지 않을까?
광고/추천 시스템처럼 topical granularity fine 한 경우,
보통 사용자가 그 task 에 passive 한 경우가 많다.
동시에 context 도 poor 하다. (예를들어 사용자는 별도의 쿼리를 입력하지 않는다.)
LLM 처럼 topical granularity 가 coarse 한 경우,
그 task 에 active 하고, rich context 를 가진다. (사용자는 장문의 쿼리를 입력 한다.)
검색은 이 중간즘 될것이다.
그렇기에 LLM 과 추천/광고 모두에게 하나의 컴포넌트로써도 사용 되기도 하는듯 하다.
검색은 광고/추천에서 topical granularity 를 높혀 주기 위해 사용되기도 하며
LLM 기반의 RAG 에서 다양한 롱테일 정보를 제공함으로써 topical granularty 를 낮춰 주기 위해 사용되기도 한다.

상기 projection 공간에 다양한 서비스/미디어가 올라갈 수 있다.
검색, 광고/추천, LLM 비롯하여,
고전적 미디어로는,
신문, 짜리시, 엄마의 잔소리, 많은 informational task 가 올라갈 수 있겠다.
미래적 미디어로도 이미 일부는 현재인 LLM 기반 시스템 을 포함하여,
미래형 자동차, 로봇 등이 미디어로써 올라갈 수 있을 것이다.
그리고 그것 하나하나가 연구주제이자 동시에 사업 주제가 된다.
하나하나가 informational task 분야의 회사들이 속할 수 있는 projection region 이 된다.
